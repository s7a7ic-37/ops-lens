Validation made the choice. This later holdout table tests it. WAPE is error, not accuracy. A change of +10 percentage points means more error than the simple baseline.

MAE is the average absolute error in units per day. WAPE is total absolute error divided by total observed units; lower is better. It is not an accuracy percentage.

03 / SHOW YOUR WORK

Can we trust the input?

SQL classification, explicit exclusions, and a reproducible Python pipeline.

Every row accounted for

How the comparison works

  1. Classify first. Separate positive product orders, cancellation proxies, adjustments and unusable lines. Customer identifiers are not retained.
  2. Choose before looking ahead. Select the eight largest products using orders up to 13 Oct. Compare two simple baselines on 14 Oct–10 Nov validation data, then compare the better baseline with gradient boosting.
  3. Freeze the choice. Evaluate each chosen method on 11 Nov–8 Dec holdout data. Refit at each weekly origin using only earlier observations.
  4. Show the limits. Orders are observed purchases, not unconstrained demand. Bulk orders, stockouts and seasonal changes can defeat every method.
